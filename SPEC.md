# Специфікація проекту: Веб-сторінка «Пляшка для води» (AquaBottle)

## 1. Загальний опис проекту
Створення інформаційної промо-сторінки (лендінгу) для продукту **«Екологічна пляшка для води» (Eco Water Bottle)**. Сторінка призначена для демонстрації переваг, характеристик, галереї продукту та надання форми для замовлення/зворотного зв’язку.

---

## 2. Головні технічні вимоги
- **Мова розмітки та стилізація:** Суто чистий семантичний **HTML5** з вбудованими стилями **CSS3** (внутрішній CSS у тегу `<style>` усередині HTML-документа, без використання окремих `.css` файлів та без сторонніх CSS/JS бібліотек чи фреймворків).
- **Повна відсутність JavaScript:** Проект реалізовано суто на HTML5 та CSS3 без жодного рядка JavaScript-коду (0% JS).
- **Оформлення та веб-дизайн:** Сучасний естетичний дизайн, гармонійна свіжа колірна палітра, адаптивна верстка (Flexbox / Grid), мікро-анімації та стилізовані елементи форм та таблиць.
- **Валідність:** Відповідність стандартам W3C HTML5 та CSS3.
- **Доступність (a11y):** Наявність коректних атрибутів `alt` для зображень, зв'язка `<label>` та `<input>` через атрибут `for` / `id`, семантичні заголовки (`<h1>`–`<h3>`).
- **Кодування:** UTF-8.
- **Адаптивність розмітки:** Використання мета-тегу `<meta name="viewport" content="width=device-width, initial-scale=1.0">`.

## 3. Структура сторінки та обов'язкові HTML-елементи

### 3.1. Шапка сайту (`<header>`)
- **Логотип / Назва:** Заголовок першого рівня `<h1>` з назвою бренду (наприклад, `AquaPure Bottle`).
- **Навігація (`<nav>`):** Невпорядкований список (`<ul>`, `<li>`) з якірними посиланнями (`<a href="#...">`):
  - *Про пляшку* (`#about`)
  - *Характеристики* (`#specs`)
  - *Переваги* (`#benefits`)
  - *Галерея* (`#gallery`)
  - *Замовити* (`#order`)
  - *Контакти* (`#contacts`)

### 3.2. Головний банер / Hero-блок (`<section id="hero">`)
- Головний заклик до дії: Заголовок `<h2>` (наприклад, *«Ваша ідеальна пляшка для води щодня»*).
- Короткий опис: Параграф `<p>` про збереження температури, екологічність та ергономічність.
- Головне зображення товару: Тег `<img>` з детальним описом у `alt`.
- Швидка дія: Кнопка-якір `<a href="#order">` (*«Замовити зараз»*).

### 3.3. Блок «Про продукт» (`<section id="about">`)
- Заголовок розділу `<h2>`.
- Опис матеріалів (харчова нержавіюча сталь 18/8, BPA-Free кришка).
- Цитата або девіз через тег `<blockquote>`.

### 3.4. Технічні характеристики (`<section id="specs">`)
- Заголовок `<h2>`.
- Таблиця характеристик (`<table>`):
  - `<thead>`: Стовпці «Параметр» та «Значення».
  - `<tbody>`:
    - Об'єм: 500 мл / 750 мл / 1000 мл
    - Матеріал: Нержавіюча сталь, силікон, бамбук
    - Збереження температури: Холодна — 24 год, Гаряча — 12 год
    - Вага: 280 г (порожня)
    - Герметичність: 100% захист від протікання
    - Діаметр шийки: 45 мм (підходить для льоду)

### 3.5. Переваги та особливості (`<section id="benefits">`)
- Заголовок `<h2>`.
- Список переваг через впорядкований/невпорядкований список (`<ul>` або `<ol>`):
  - Екологічність (заміна 1500+ одноразових пластикових пляшок на рік).
  - Подвійні вакуумні стінки (не нагрівається зовні, не збирає конденсат).
  - Зручний тримач / ремінець для носіння.
  - Легко миється, підходить для спорту, офісу та подорожей.

### 3.6. Медіа / Галерея (`<section id="gallery">`)
- Заголовок `<h2>`.
- Блоки фігур `<figure>` із зображеннями (`<img>`) та підписами (`<figcaption>`):
  - Пляшка на природі / у поході.
  - Пляшка в спортзалі.
  - Деталі кришки та герметичного клапана.

### 3.7. Інтерактивна форма замовлення (`<section id="order">`)
- Заголовок `<h2>`.
- HTML-форма (`<form action="#" method="post">`):
  - `<fieldset>` з `<legend>` «Контактні дані покупця»:
    - ПІБ (`<input type="text" name="fullname" required>`)
    - Телефон (`<input type="tel" name="phone" required placeholder="+380...">`)
    - Email (`<input type="email" name="email">`)
  - `<fieldset>` з `<legend>` «Параметри замовлення»:
    - Вибір кольору (`<input type="radio" name="color">` або `<select>`: Матовий чорний, Океанічний синій, Смарагдовий, Срібний).
    - Вибір об'єму (`<select name="volume">`: 500 мл, 750 мл, 1000 мл).
    - Кількість (`<input type="number" name="quantity" min="1" max="10" value="1">`).
    - Додаткові опції (`<input type="checkbox" name="extra">`: Чохол для пляшки, Щітка для чищення).
    - Коментар до замовлення (`<textarea name="comment" rows="4"></textarea>`).
  - Кнопка відправки: `<button type="submit">Оформити замовлення</button>`.
  - Кнопка скидання форми: `<button type="reset">Очистити</button>`.

### 3.8. Підвал сайту (`<footer>`)
- Секція контактів (`<address>`): номер телефону, email, посилання на соцмережі.
- Повідомлення про авторські права: `<p>&copy; 2026 AquaPure Bottle. Всі права захищено.</p>`.

## 4. Критерії приймання (Acceptance Criteria)
1. Файл зберігається як `index.html` або відповідний HTML-документ.
2. Код написаний суто на чистому HTML5 із внутрішніми стилями CSS3 у тегу `<style>` усередині HTML-файлу (без використання JavaScript, без окремих `.css` файлів та без зовнішніх бібліотек/фреймворків).
3. Усі секції мають правильні семантичні теги (`header`, `main`, `section`, `article`, `figure`, `footer`, `form`, `table`).
4. Форма містить необхідні типи полів (`text`, `tel`, `email`, `number`, `radio`, `checkbox`, `select`) з валідаційними атрибутами (`required`, `min`, `max`).
5. Усі посилання в навігації працюють через якірні переходи (IDs).
