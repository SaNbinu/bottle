# Технічне завдання (SPEC)
## Навчальний HTML-лендінг: «ThermoKeep»

---

## 1. Загальний опис проєкту

- **Назва проєкту:** Лендінг «ThermoKeep» (Навчальне видання)
- **Продукт / Бренд:** ThermoKeep — стильні вакуумні термоси та термопляшки з нержавіючої сталі для навчання, роботи та щоденного використання.
- **Цільова аудиторія:** Студенти та учні, які вивчають базові теги мови розмітки HTML.
- **Технічні обмеження:**
  - **Виключно чистий HTML** (без CSS-стилів, без підключення файлів стилів, без JavaScript).
  - Використовуються лише стандартні, зрозумілі для початківців HTML-теги.
  - Головна мета — опанувати семантичну структуру документа, правильну вкладеність тегів, роботу з формами, таблицями, списками та обов'язковими атрибутами.

---

## 2. Навчальні цілі для студентів

Виконуючи це завдання, студент повинен навчитися та продемонструвати:
1. Створення базового скелета документа HTML5 (`<!DOCTYPE html>`, `<html>`, `<head>`, `<title>`, `<meta charset="UTF-8">`, `<body>`).
2. Побудову чіткої ієрархії заголовків (`<h1>`, `<h2>`, `<h3>`).
3. Роботу з текстом і рядковими елементами (`<p>`, `<strong>`, `<em>`, `<hr>`, `<br>`).
4. Додавання зображень із обов'язковими атрибутами (`<img>`, `src`, `alt`, `width`, `height`).
5. Створення зовнішніх та внутрішніх навігаційних посилань (`<a>`, `href`, внутрішні якірні посилання `#id`, `mailto:`, `tel:`).
6. Оформлення маркованих (`<ul>`) та нумерованих (`<ol>`) списків (`<li>`).
7. Створення структурованих таблиць даних (`<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`).
8. Розробку інтерактивних вебформ (`<form>`, `<label>`, `<input>`, `<select>`, `<option>`, `<textarea>`, `<button>`).

---

## 3. Схема та структура сторінки

Вебсторінка є односторінковим сайтом (landing page) і повинна містити 7 послідовних блоків:

```
+-----------------------------------------------------------------+
| 1. Шапка та навігація (Назва бренду <h1>, якірні посилання)     |
+-----------------------------------------------------------------+
| 2. Головний блок / Hero (Гасло <h2>, опис <p>, фото <img>, CTA) |
+-----------------------------------------------------------------+
| 3. Переваги та характеристики (<h3>, маркований список <ul>)   |
+-----------------------------------------------------------------+
| 4. Інструкція користувача (<h3>, нумерований список <ol>)       |
+-----------------------------------------------------------------+
| 5. Таблиця порівняння моделей (<h3>, таблиця <table>)           |
+-----------------------------------------------------------------+
| 6. Форма передзамовлення (<h3>, форма <form> з полями вводу)    |
+-----------------------------------------------------------------+
| 7. Підвал / Контакти (Розділювач <hr>, контакти, копірайт)      |
+-----------------------------------------------------------------+
```

## 4. Детальний опис кожного розділу

### Розділ 1: Шапка сайту та Навігація
- **Контейнер:** `<header>` або базовий `<div>`
- **Головний заголовок сторінки:**
  - `<h1>ThermoKeep</h1>`

- **Навігаційне меню:**
  - Маркований список `<ul>` із внутрішніми якірними посиланнями для швидкого переходу по сторінці:
    - `<a href="#hero">Головна</a>`
    - `<a href="#features">Переваги</a>`
    - `<a href="#instructions">Інструкція</a>`
    - `<a href="#models">Моделі</a>`

### Розділ 4: Інструкція з експлуатації

### Розділ 6: Форма замовлення та зворотного зв'язку
- **Ідентифікатор для якоря:** `id="order"`
- **Вміст розділу:**

  - Форма: `<form action="#" method="post">`
  - Обов'язкові поля вводу (кожне поле обов'язково пов'язане з `<label>` через атрибути `for` та `id`):
    1. **Ім'я замовника:**
       - `<label for="client-name">Ваше повне ім'я:</label>`

    2. **Електронна пошта:**
       - `<label for="client-email">Електронна пошта (Email):</label>`

    3. **Номер телефону:**
       - `<label for="client-phone">Номер телефону:</label>`
       - `<input type="tel" id="client-phone" name="client_phone" placeholder="+380XXXXXXXXX" required>`
    4. **Вибір моделі (Випадаючий список):**
       - `<label for="client-model">Оберіть модель термоса:</label>`

         - `<option value="classic" selected>ThermoKeep Classic (500 мл)</option>`
         - `<option value="travel">ThermoKeep Travel Max (750 мл)</option>`

    5. **Кількість (Числове поле):**

    6. **Колір термоса (Перемикачі / Radio buttons):**
       - `<p>Оберіть колір корпусу:</p>`
       - `<input type="radio" id="color-black" name="color" value="black" checked>`

## 5. Зведений чекліст обов'язкових HTML-тегів

| Категорія | Обов'язкові теги для реалізації |
| :--- | :--- |
| **Каркас документа** | `<!DOCTYPE html>`, `<html>`, `<head>`, `<title>`, `<meta charset="UTF-8">`, `<body>` |
| **Заголовки** | `<h1>`, `<h2>`, `<h3>` |
| **Текст та розділювачі** | `<p>`, `<strong>`, `<em>`, `<br>`, `<hr>` |
| **Посилання** | `<a href="...">`, `<a href="#id">`, `<a href="mailto:...">`, `<a href="tel:...">` |
| **Зображення** | `<img src="..." alt="..." width="..." height="...">` |
| **Списки** | `<ul>`, `<ol>`, `<li>` |
| **Таблиці** | `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>` |
| **Форми та введення** | `<form>`, `<label>`, `<input type="text|email|tel|number|radio">`, `<select>`, `<option>`, `<textarea>`, `<button>` |

## 6. Критерії оцінювання та прийому роботи викладачем

1. **Суворий HTML-only:** У файлі немає жодного CSS-стилю (заборонено використовувати тег `<style>` та атрибут `style=""`) і жодного рядка JavaScript.
2. **Семантична ієрархія:** На сторінці присутній тільки один тег `<h1>`. Заголовки спадають логічно: `<h1>` &rarr; `<h2>` &rarr; `<h3>`.
3. **Доступність (Accessibility):** Усі зображення `<img>` містять інформативний атрибут `alt`. Усі поля введення форми мають відповідний `<label>` із правильно зв'язаними `for` та `id`.
4. **Робоча навігація:** Усі внутрішні посилання з меню (`#hero`, `#features`, `#instructions`, `#models`, `#order`, `#contacts`) коректно переходять до відповідних блоків.
5. **Акуратність коду:** Код правильно відформатований, використовуються однакові відступи (2 або 4 пробіли), усі парні теги закриті.
